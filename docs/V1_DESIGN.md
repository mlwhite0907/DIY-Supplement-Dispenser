# V1 Design

This document records the confirmed V1 product direction. It intentionally does
not select parts, vendors, dimensions, electronics, or mechanical designs.

## System shape

V1 has two separate output paths:

- A drink station for preparing the liquid portion.
- A separate dry pill dispensing tray for the dry portion.

The drink station uses:

- A removable, refillable water tank.
- Food-safe tubing.
- A peristaltic pump.

The dry dispensing system uses 12 removable, sealed powder cartridges. Each bay
has one controlled dispensing mechanism.

## Dosing model

Recipes are dosed by cumulative grams. A load cell verifies the delivered dose as
the recipe is dispensed. Scoop-based dosing is not the V1 dosing model.

Powder calibration and anti-clogging are core design requirements, not optional
later enhancements.

## Deliberately undecided

No parts have been purchased or selected yet. Implementation details—including
the electronics, motors, sensors, cartridge geometry, pump specification,
control software, and enclosure—remain open until the design is developed
further.

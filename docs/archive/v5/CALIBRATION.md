# Calibrate a head (5 minutes, once per powder)

The dial measures **volume** (mL). Powders differ in how much a mL weighs, so you check each powder once with a kitchen scale. After that, every pull repeats.

## What you need

- A kitchen scale (0.1 g is nice; 1 g works if you weigh 5 pulls together)
- A cup
- Your powder's serving size in grams (from the label)

## Steps

1. **Set the starting point.** Turn the dial to the starting setting from `DIAL_SETTINGS.md`. For caffeinated powders, start at **70 %** of that number.
2. **Prime.** Pull and release twice into any cup, then empty it. The first pull after filling can be light.
3. **Weigh 5 pulls.** Tare the cup. Pull **all the way to the stop**, let the drawer spring back, and repeat 5 times. Write down the total.
4. **Work out the new setting:**

   ```
   grams per pull = total ÷ 5
   new setting    = current setting × (target grams ÷ grams per pull)
   ```

   Round to the nearest click.
5. **Check.** Do 3 more pulls at the new setting. You should be within one click of the target.

### Example

| | |
|---|---|
| Target | 13.5 g per serving |
| Starting setting | 25 mL |
| 5 pulls weigh | 61.0 g → 12.2 g per pull |
| New setting | 25 × 13.5 ÷ 12.2 = 27.7 → **28 mL** |
| Check pulls | 13.4, 13.6, 13.5 g ✓ |

## Recalibrate when

- You switch brand or flavor. Flavors of the same product can differ by 10–20 %.
- The powder clumped or the weather turned very humid.
- You washed the head and the jar.

## Getting the most repeatable doses

- Pull **all the way** to the stop each time, then let go completely.
- One pull = one dose. Doing 2 pulls back to back is fine for a double serving. The second may be 2–3 % lighter for fluffy powders.
- If a pull comes out light, the powder bridged. The stir post makes this rare. A tap on the jar fixes it.
